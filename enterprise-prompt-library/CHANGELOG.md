## [1.0.0] — 2026-08-07

### Added

- **Core Rules** — Constitution (Articles 0–14), Principles, Architecture
  Rules, Specification-Driven Development, Workflow (Stage 0–7), Quality Gates
  G0–G7, Decision Rules, AI Behaviour, Coding Standards, Documentation
  Standards, Security Principles, Privacy Principles, Child Protection,
  Traceability, Explainability, Glossary, Terminology.
- **Platform Adapters** — Lovable, Cursor, GitHub Copilot, Claude Code, Codex,
  Gemini CLI, Cline, Roo Code, Continue, Windsurf, Aider, Bolt.new, v0, each
  with context-window, prompt, iteration, memory, file, validation, and review
  strategies.
- **Task Templates** — Vision, Stakeholder Map, PRD, ADR, Domain Model,
  Canonical Data Model, Domain Events, Business Journey, Logical Data Model,
  Physical Data Model, API Contract, OpenAPI, UI Component, Screen Catalogue,
  Design System, UX Architecture, Authorization, RLS, Migration, Testing,
  Performance, Observability, DevOps, CI/CD, Documentation, Release.
- **Validation Prompts** — Architecture, Domain, DDD, Security, Privacy, Child
  Protection, Performance, Accessibility, API, UI, Data, SQL, Migration,
  Testing, AI Governance, Specification, Traceability, Constitution Compliance,
  plus the G0–G7 gate runner.
- **Release Prompts** — PR review, architecture review, code review, security
  scan, dependency review, migration readiness, deployment readiness, release
  notes, changelog, rollback plan, post-release review, production readiness.
- **Product docs** — README, GOVERNANCE, CONTRIBUTING, ROADMAP, authoring
  guide, adoption guide, versioning policy, deprecation policy, migration
  guide, traceability model, examples.

### Deprecated

- Nothing. This is the initial release.

### Migration

  installation into an existing repository.
